# 🏦 Six Sigma DMAIC: Bank Call Center Optimization
This project applies Lean Six Sigma (LSSGB) methodologies to improve the operational efficiency of a Bank Call Center.

### 🎯 Project Objective
To reduce "Average Handle Time" (AHT) and improve "First Call Resolution" (FCR) rates by identifying bottlenecks in the call-handling process.

### 🔍 DMAIC Framework Applied
* **Define:** Identified high customer wait times as the primary "Critical to Quality" (CTQ) issue.
* **Measure:** Analyzed `call_center_data.xlsx` to establish baseline performance metrics.
* **Analyze:** Used Pareto Charts and Fishbone Diagrams to identify the root causes of long hold times.
* **Improve:** Proposed a streamlined IVR (Interactive Voice Response) routing system.
* **Control:** Implemented Control Charts (Cp/Cpk) to monitor ongoing performance.

### 📊 Tools Used
* **Lean Six Sigma:** DMAIC Methodology.
* **Excel:** Data analysis, Pivot Tables, and Pareto visualization.
* **Statistical Analysis:** FMEA (Failure Mode and Effects Analysis) and SIPOC.
